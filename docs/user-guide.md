# How to play

This guide is still being written (issue #45). The short version:

1. Open the game link on your phone, in Safari (iPhone) or Chrome (Android).
2. Type your team code, read the photo notice, tick the box and tap **Join**.
3. Allow the camera and location when asked.
4. Wait for the moderator to start the game. The screen moves on by itself.
